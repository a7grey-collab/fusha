# FUSHA

Интерактивный прототип сервиса изучения арабского языка (фусха) для всего мира. Один HTML-файл без внешних запросов: уроки, повторение, AI-тьютор (демо), запись голоса, тарифы, профиль. Языки: русский, English, العربية.

**Открыть онлайн:** https://a7grey-collab.github.io/fusha/

## Версии

Каждая версия лежит в папке [`versions/`](versions/) и называется `Fusha_App_Prototype_vN.html`. Файл `index.html` всегда равен последней версии. Что менялось, смотрите в [CHANGELOG.md](CHANGELOG.md).

## Запуск и сборка

Откройте `index.html` в браузере. Для пересборки из исходников в `src/` выполните `python3 build.py`.

## Установка на экран и обновления (с v4)
- Android (Chrome): кнопка «Установить на Android» ставит приложение одним нажатием.
- iPhone/iPad (Safari): кнопка «Добавить на iPhone / iPad» показывает шаги: Поделиться → «На экран «Домой»» → «Добавить».
- Новая версия: `build.py` обновляет `version.json` и `sw.js`; открытое приложение проверяет `version.json` при возврате на вкладку и раз в 10 минут и показывает «Доступно обновление».

## Аудио (с v12)
Клипы лежат в `src/audio/` (manifest.json: id → файл) и вшиваются в HTML при сборке. Это синтезированный голос для прототипа. В продакшене заменить на записи диктора (для Корана: чтецы, например EveryAyah).
